Raspberry Pi im September 2026: Neuer Desktop mit Dock und ein 14-MB-Sprachmodell, das auf dem Pi 5 Befehle ausführt

Teilen: WhatsApp Facebook X (Twitter)

Zwei Nachrichten aus Cambridge, die Bastler interessieren: Raspberry Pi hat am 15. September 2026 seinem Desktop das größte optische Update seit Jahren verpasst, und am 22. September zeigte das Unternehmen mit Needle 2, wie ein winziges Sprachmodell auf dem Raspberry Pi 5 ohne KI-Beschleuniger Befehle in Aktionen übersetzt. Beides ist kostenlos – und beides ändert, was ein Pi im Alltag leisten kann.

Der neue Desktop: Dock, Launcher, Screenshot-Werkzeug

Das Update bringt einen optionalen Icon-Dock mit Widgets und Statusbereich, einen grafischen App-Launcher statt des alten Hauptmenüs, eine kombinierte Taskleiste mit Fensterzähler, einen Analoguhr-Modus, ein Screenshot-Werkzeug mit Bereichsauswahl und eine neue Einstellungsseite für Tastenkürzel. Drei Voreinstellungen stehen zur Wahl: „Taskbar“, „Taskbar/Dock“ und „Dock“, jeweils mit Autohide, frei positionierbar, mit Farb- und Größenoptionen. Für schwache Systeme gibt es ein leichtgewichtiges Hintergrund-Rendering per swaybg.

Wichtig: Alles ist optional. Wer nichts umstellt, behält den gewohnten Desktop. Aktiviert wird der neue Look im Control Centre auf der Seite „Defaults“. Voraussetzung ist Raspberry Pi OS auf Basis von Debian 13 „Trixie“; auf das ältere Bookworm wird das Update nicht zurückportiert. Das Update kommt per sudo apt update && sudo apt full-upgrade oder mit dem neuen Systemabbild vom 15. September. Es läuft auf allen Pi-Modellen; unter 2 GB RAM empfiehlt Raspberry Pi, die Speicherspar-Optionen zu nutzen.

Needle 2: Sprachbefehle in Funktionsaufrufe – ohne Cloud, ohne HAT

Needle 2 ist kein Chatbot. Das 14 MB kleine Modell des Anbieters Cactus Compute tut nur eines: Es wandelt Klartext-Anweisungen in Python-Funktionsaufrufe um. Entwickler markieren ihre Funktionen mit dem Dekorator @needle.tool samt Docstring und Typangaben; Needle wählt die passende Funktion und füllt die Argumente. Auf einem Raspberry Pi 5 lief das laut Raspberry Pi auf der reinen CPU: Ein „Turn the LED on“ brauchte 78 Millisekunden, andere Befehle 76 bis 149 Millisekunden. Die Python-Sitzung belegte dabei rund 28 MB, der gesamte Prozess unter 47 MB.

Das Modell steht unter Apache-2.0-Lizenz, die Gewichte liegen bei Hugging Face (Cactus-Compute/needle2), installiert wird per pip install cactus-needle. Für Smart-Home-Projekte ist das spannend: Ein lokal laufender Sprachbefehl-Parser, der ohne Internet in Echtzeit reagiert, war bislang nur mit deutlich mehr Hardware zu haben. In Verbindung mit einem Sprach-zu-Text-System wie in unserer Anleitung zum Whisper-Sprachassistenten entsteht daraus eine komplett lokale Sprachsteuerung.

Einordnung

Das Desktop-Update ist Kosmetik mit Nutzen – vor allem der Launcher und das Screenshot-Werkzeug bringen den Pi näher an das, was Umsteiger von Windows oder macOS erwarten. Needle 2 dagegen ist ein Fingerzeig, wohin lokale KI geht: nicht größere Modelle, sondern winzige Spezialisten, die eine Aufgabe schnell und offline erledigen. Wer damit experimentieren will, braucht nur einen Pi 5 – kein AI-HAT. Hardware: Raspberry Pi 5 bei Amazon (Werbung) · offizielles 27-W-Netzteil bei Amazon (Werbung)

Häufige Fragen

Wie bekomme ich den neuen Raspberry-Pi-Desktop?

Auf Raspberry Pi OS „Trixie“ per sudo apt update && sudo apt full-upgrade, dann im Control Centre unter „Defaults“ den Stil wählen. Bookworm erhält das Update nicht.

Braucht Needle 2 einen AI-HAT?

Nein. Laut Raspberry Pi läuft Needle 2 auf der CPU des Raspberry Pi 5 mit Antwortzeiten zwischen 76 und 149 Millisekunden.

Ist Needle 2 kostenlos?

Ja, Apache-2.0-Lizenz; Code auf GitHub (cactus-compute/needle), Gewichte auf Hugging Face.
